# STM32 手写表达式计算器

这是一个运行在 STM32F407ZGTX 开发板上的手写表达式计算器。触摸屏采集笔迹，程序分割字符后使用片上 CNN 识别数字和四则运算符，并在 LCD 上显示表达式与结果。

当前仓库以 `v1.1.2` 作为最新版稳定基线。该版本已完成上板验证，已知问题是 LCD 笔迹轨迹显示存在轻微偏移；神经网络识别稳定性优先保持不变。

## 工程信息

- MCU：STM32F407ZGTX，Cortex-M4F，168 MHz
- 工程：STM32CubeIDE / CubeMX
- 显示与触摸：FSMC LCD、I2C 触摸控制器
- 识别类别：数字 `0`–`9`、加减乘除

## 使用方式

1. 使用 STM32CubeIDE 导入仓库根目录工程。
2. 根据开发板确认 HSE、LCD 接线、触摸控制器和校准数据。
3. 选择 `Debug` 或 `Release` 构建并下载到目标板。
4. 首次触摸屏异常时按 `KEY0` 进入校准；在底部区域书写，点击左上角预测。

仓库不保存 `Debug/`、`Release/` 编译产物，这些目录由 CubeIDE 在本机生成。

## 当前限制

- 字符按水平方向连续笔迹分割，字符之间需要留出空白列。
- 表达式使用整数四则运算，除数为零会显示错误。
- 笔迹显示存在轻微位置偏移，后续修改显示时应避免改变 CNN 输入链路。
